A note on supported HTML & CSS

This is an early renderer, so some browser CSS may differ. JavaScript is not executed. Upload a single self-contained HTML file (up to 2 MiB); linked stylesheets, remote images, and local file references are not loaded. Documents are limited to 100 pages and 60 seconds of conversion. CSS @page margins override the margin setting; enable “Prefer CSS page size” to use CSS page dimensions too. Source code is kept in memory and is cleared when you leave or reload.
